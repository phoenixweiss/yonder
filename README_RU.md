Yonder — небольшая настольная утилита, которая хранит файлы в обычной папке
хранилища и делает их доступными по путям, где их ожидают локальные приложения.

> **Yonder не предоставляет собственный сервис синхронизации. Файлы остаются в обычной папке, а синхронизацией занимается внешний облачный клиент.**

У Yonder нет учётной записи, сервера, телеметрии или фонового сервиса синхронизации.

## Как это работает

Каждое подключение связывает один источник в хранилище с одним назначением на
компьютере:

```text
Хранилище                         Компьютер
файл или папка-источник   ->      символическая ссылка по пути назначения
```

Yonder поддерживает связи «файл → файл» и «папка → папка». Источник остаётся
настоящим объектом файловой системы, а назначение становится символической ссылкой.
Подключения записываются в строгий человекочитаемый файл `yonder.yaml`. См.
[пример конфигурации](examples/yonder.yaml).

Приложение умеет:

- создавать и открывать хранилище;
- проверять все настроенные подключения без изменения файлов;
- добавлять подключение после отдельного просмотра и подтверждения;
- создавать по одной проверенной символической ссылке;
- отключать ссылку без удаления источника или конфигурации;
- удалять безопасно отключённое подключение из конфигурации.

## Безопасность

Yonder выполняет только явные и узко ограниченные изменения файловой системы.
Перед записью приложение повторяет существенные проверки и запрашивает финальное
подтверждение. Оно отказывается заменять занятое назначение, создавать отсутствующие
родительские папки или продолжать работу после изменения конфигурации или файлов.

Открытие и повторная проверка хранилища выполняются только для чтения. Yonder никогда
не перемещает данные источника, а при отключении удаляет только точную проверенную
символическую ссылку.

## Скачать

Yonder пока распространяется как ранняя публичная предварительная версия. Текущий релиз —
[Yonder 0.1.2](https://github.com/phoenixweiss/yonder/releases/tag/v0.1.2) для Mac
с Apple silicon под управлением macOS 13 или новее.

Сборка для macOS защищена ad-hoc подписью для контроля целостности, но ещё не
подписана Developer ID и не нотаризована. Поэтому macOS потребует явного разрешения
при первом запуске. После копирования Yonder в «Программы» щёлкните приложение с
зажатой клавишей Control, выберите **Открыть** и подтвердите запуск. Контрольные
суммы опубликованных файлов находятся в `SHA256SUMS.txt`.

Пути для Linux и Windows предусмотрены форматом конфигурации, но эти платформы пока
не объявлены поддерживаемыми, поскольку не прошли нативную проверку.

## Разработка

Требования:

- Node.js 24
- Yarn Classic 1.22.22 через Corepack
- системный Clang на macOS для нативного помощника ссылок

Установка зависимостей и полный набор проверок:

```sh
corepack yarn install --frozen-lockfile
corepack yarn quality
```

Основные команды:

```sh
corepack yarn dev                 # открыть окно Electron для разработки
corepack yarn package:mac:dir     # собрать локальное приложение .app
corepack yarn package:mac         # собрать локальные DMG- и ZIP-артефакты
```

Версии выпускаются через [Bumpster](https://github.com/phoenixweiss/Bumpster).
Проектная конфигурация синхронизирует `VERSION` и `package.json`, а pre-bump hook
запускает полный набор проверок и закрывает секцию `Unreleased` changelog в том же
version-коммите. Созданный тег запускает релизный workflow GitHub Actions. Локальная
упаковка ничего не публикует.

Интерфейс построен на Vue 3 и Vite. Electron остаётся тонкой desktop-оболочкой:
нативные диалоги и файловые операции выполняются в main process за узким preload
API. Английский — канонический язык проекта; русский интерфейс и README
поддерживаются синхронно с ним.

Просим сохранять границы продукта: обычные файлы, символические ссылки, явное
подтверждение и отсутствие встроенного сервиса синхронизации.

Пользовательские изменения перечислены в [журнале изменений](CHANGELOG.md).
